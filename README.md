# Колесо фортуны

Встраиваемый виджет «Колесо фортуны» – копия по виду и поведению виджета Calltouch с meridian.xfit.ru (снят 10.11.2026).
Демо: https://tema-mail.github.io/fortune-wheel/

## Что внутри

- `site/fortune-wheel.js` – виджет одним файлом, без зависимостей, стили изолированы в Shadow DOM. Ставится на любой сайт: Astro, Тильда, любой HTML.
- `site/index.html` – демо-страница.
- `tema.py` – тёмная тема на демо-странице; запускается в сборке и валит её, если темы нет.

Почему не Preact: виджет вставляется и на сайты не на Astro (Тильда), поэтому чистый JS без сборки.

## Как устроено (снято с оригинала)

- Карточка 400 px, сверху нижняя половина колеса 500 px, белая стрелка снизу по центру.
- 10 секторов по 36°, цвета чередуются `rgba(54,188,70)` / `rgba(1,205,196)`, призы идут по кругу (6 призов → 10 секторов).
- В покое колесо повёрнуто на −72°, видны первые 4 приза.
- Вращение: 4 полных оборота + сектор приза + случайный сдвиг 1–34° внутри сектора, 7 секунд, торможение `easeOutSine`, через 0,3 с – экран приза.
- Во время вращения кнопка бледнеет, на ней три бегущие полоски.
- Пустые поля: фон `rgba(253,242,242)`, текст `rgba(203,36,36)`.
- Экран приза: промокод в пунктирной рамке (клик – копирует, иконка меняется на галочку), название приза, «Мы свяжемся с вами…».
- Само всплывает через 10 с, второй раз через 100 с, если закрыли, не покрутив. После выигрыша не всплывает, кнопка в углу показывает приз.
- Звука у колеса в оригинале нет.

## Отличия от оригинала

- Нет подписи «Сделано в Calltouch».
- Шрифт Manrope (в оригинале платный TT Norms Medium).
- Пустая галочка согласия: без неё заявка не уходит (`consentCheckbox: false` – как в оригинале, без галочки).
- Приз выбирает виджет (`weight` у приза – вес), промокоды задаются в настройках. В оригинале приз и код выдаёт сервер Calltouch.

## Подключение

```html
<script>
window.FortuneWheelConfig = {
  endpoint: 'https://сервер/lead',            // POST JSON заявки
  privacyUrl: '/privacy-policy',
  metrika: { id: 12345678, goal: 'wheel_spin' },
  prizes: [{ name: 'Скидка 15% на абонемент', code: 'SALE15', weight: 1 }]
};
</script>
<script src="https://tema-mail.github.io/fortune-wheel/fortune-wheel.js" defer></script>
```

Все настройки и значения по умолчанию – в начале `site/fortune-wheel.js` (`DEFAULTS`).
API: `FortuneWheel.open()`, `FortuneWheel.close()`, `FortuneWheel.reset()`, `FortuneWheel.state()`.

В заявке: имя, телефон `+7XXXXXXXXXX`, приз, промокод, страница и referrer, метки utm / yclid / gclid первого захода и текущей страницы.

## Перед боем на сайте клиента

- Указать `endpoint` (или `onLead`) – без него заявка никуда не уходит.
- Заменить промокоды на настоящие, при желании задать веса призов.
- Указать настоящую ссылку на политику обработки ПД.
